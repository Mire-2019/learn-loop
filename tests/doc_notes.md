# learn-loop 设计笔记（测试用文档）

## 为什么要做这个闭环

模型直接看视频链接时，往往只拿到三五张关键帧，而且字幕还经常与画面错配。
结果是它会写出读起来很顺、但无法核对的“学习笔记”。

## 三条硬规则

### 1. 证据先行

任何结论都必须能落到一条可复核的证据上：视频是时间戳加帧文件，
文档是行号，字幕是分句的时间区间。

### 2. 引用必须可解析

引用不是装饰。判据机检会逐条检查引用 id 是否存在于证据索引，
以及引用指向的文件是否真的在磁盘上。

### 3. 覆盖率是物理体检

字幕与视频是否匹配，不靠感觉，靠覆盖率与跳段检测：
覆盖率低于 50% 或高于 105%，或者存在超过 20 秒的跳段，一律判可疑。

## 已知局限

mock 模式只能产出结构性结论（时长、帧数、行号、逐字引用），
它不会假装看懂了画面内容；语义层面的结论必须由真实模型或人来补。
